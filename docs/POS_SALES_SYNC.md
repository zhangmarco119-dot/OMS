# 收银系统营业收入同步

## 当前范围

- OMEGA 酸奶（西直门店）使用银豹收银系统。
- 宝珠奶酪（五道口店）预留企迈接入，本阶段不读取、不混用企迈数据。
- 西直门默认每天北京时间 10:00–22:00、每 30 分钟自动更新；管理员可在“实时薪资 → 营业收入”调整为每 15、30、60 或 120 分钟，也可暂停自动更新。
- 管理员可选择今天或历史日期手动更新。每次更新会重新读取该日银豹单据，并原子替换该日核算结果。

## 收入口径

系统调用银豹 `queryTicketPages` 分页查询所选自然日：

1. 有效 `SELL` 单据按 `totalAmount` 加入收入。
2. 有效 `SELL_RETURN` 单据按金额绝对值从收入扣减。
3. `invalid` 单据不进入收入。
4. 同一外部单据键去重；每次更新以本次银豹完整日数据替换旧数据。
5. 更新成功后写入 `payroll_store_revenues`，来源标记为 `pospal`，直接参与实时薪资中的营业额提成口径。

自动任务每 5 分钟只在数据库内检查是否到达某门店的下次更新时间。只有处于设置时段且确实到期时才请求 Edge Function 和银豹，因此默认设置下每天最多触发约 25 次基础查询；分页较多时实际 API 次数会增加。管理员页面会显示最近一次读取单据数和 API 调用数，便于控制银豹额度。

## 安全边界

- App ID、App Key 和接口 Host 只能保存为 Supabase Edge Function Secret `POSPAL_INTEGRATIONS_BASE64`。
- Secret 使用 Base64 编码的 JSON 数组，以 `storeId` 关联门店；Base64 仅用于安全传输格式，不替代 Supabase Secret 的保密能力。
- 数据库业务表只保存平台类型、外部账号标识、门店映射、计划和同步结果，不保存 App Key。
- 前端只调用 Edge Function，不能读取凭据；Edge Function 再校验管理员身份和门店权限。
- 自动任务使用数据库私有 Token；Token 不授予 `anon` 或 `authenticated` 角色读取权限。
- 标准化单据表启用 RLS 且不给浏览器读取策略，只允许 Service Role 在后端写入。
- 日志不记录 App Key、签名、完整上游响应或顾客资料。

## 环境配置

每套 Supabase 环境都必须单独部署 Migration、函数和 Secret。不要把真实值写入 `.env`、SQL、Markdown、Cloudflare 前端变量或 Git。

Secret 解码后结构如下，示例值仅为占位符：

```json
[
  {
    "storeId": "门店 UUID",
    "host": "https://对应区域的银豹主机:443",
    "appId": "银豹开放平台 App ID",
    "appKey": "银豹开放平台 App Key"
  }
]
```

配置顺序：

1. 将 `0068_pos_sales_revenue_sync.sql` 应用到目标 Supabase。
2. 在目标 Supabase 设置 `POSPAL_INTEGRATIONS_BASE64`。
3. 部署 `pospal-sales`，并关闭网关 JWT 预校验；函数内部仍做完整鉴权。
4. 由管理员在营业收入页面保存时段和频率。这一步会创建或刷新数据库 Cron。
5. 选择一天执行一次手动更新，确认同步日志、单据数、API 次数和当日营业收入。
6. 完成类型检查、Lint、测试、构建和安全扫描后，才能部署前端。

开发环境联调通过后，正式发布必须先把同一批 Migration 应用到正式数据库，再独立设置正式 Secret、部署正式 Edge Function、手动验证一次，最后部署正式前端。禁止把开发测试单据或开发 Secret 复制到正式数据库。

## 管理员操作

进入“工作台 → 实时薪资 → 营业收入”：

- “更新 YYYY-MM-DD”：立即从银豹更新当前所选日期。
- “保存更新设置”：保存自动更新开始时间、结束时间、频率和启停状态。
- “每日已确认营业收入”：仍允许人工录入；人工保存会明确把当天来源改为“手动录入”，下次银豹更新会再以银豹实际日数据覆盖。
- 页面反馈会说明读取单据数、净营业收入和本次 API 次数；失败时会保留安全化错误摘要，便于重试和排查。

## 故障处理

- “尚未完成安全配置”：检查 Secret 是否存在、是否是 Base64 编码的 JSON 数组，以及 `storeId` 是否正确。
- “认证失败”：检查银豹凭据、接口区域 Host 和开放平台授权，不要连续重试消耗额度。
- “调用次数已受限”：暂停自动更新或降低频率，并联系银豹确认额度。
- “服务暂时无法连接”：单次读取最多等待 45 秒；系统不会立即连续重试，自动计划会在下个周期再次尝试，管理员也可稍后手动更新。
- 收入与银豹不一致：先核对所选日期，再查看有效单据数、退货和作废单据；手动更新当天可重新生成完整日结果。
- 自动任务未运行：确认连接已启用、当前时间在设置时段内、`next_sync_at` 已到期，并检查最近同步日志。
