# 实时预估薪资

系统按 `员工实时预估工资计算标准.md` 计算员工从当月 1 日到所选截止日期已经产生的工资，不预测月末金额。员工从“我的薪资”进入，可在“预估薪资”和“工资单”之间切换。

## 工资单发放与确认

- 每月 1 日北京时间 00:10，数据库自动为所有在职员工和店长发放上月工资单。
- 管理员可在“实时薪资 → 工资单”选择本月或任意历史月份，为全部人员或指定员工生成草稿；逐份预览、修改并确认无误后再发送。
- 工资单保存发放时的完整薪资计算快照；发放后的实时考勤、提成等变化不会静默改写已经发放的工资单。
- 员工收到工资单后，“待办”会新增“确认工资单”。员工在“我的薪资 → 工资单”查看明细并确认后，待办和角标立即完成。
- 管理员可查看待发送、待员工确认、员工已确认和已撤回状态，并可打开工资单查看、修改或撤回。修改已经确认的工资单会取消旧确认并要求员工重新确认。

## 统计口径

- 基本工资、房补和绩效均按出勤天数折算，不展示或使用出勤小时。
- 全部授权门店范围内，同一员工同一天在多个门店出勤只计 1 天。
- 迟到、缺卡和异常合并所有授权门店记录；考勤页面选择单一门店时只显示该门店数据。
- 提成只汇总管理员在员工工资规则中指定的门店，计算基数是本月 1 日至所选截止日期的累计营业额，不是截止日当天营业额。
- 每个门店和截止日期可选择收银系统同步或手动提成基数。收银同步会汇总月内每日明细；手动方式只覆盖员工提成计算基数，不会修改银豹营业额或每日营业额明细，两种来源不会重复相加。
- 当所选截止日期尚无当天更新时，系统沿用同一自然月内最近一次有效提成基数，并在工资明细中标注基数实际更新日期；不会跨月沿用上月累计值。
- 员工可单独启用全勤奖并设置金额；当月累计出勤天数达到系统满勤天数时，奖励自动计入累计绩效奖。
- 加班按审批通过时锁定的时薪单独计入；待审批或已驳回申请不进入工资合计。
- 任务或营业收入缺失时，对应金额显示“待更新”，不能作为完整最终金额。
- 李荣珊、李荣妹、李荣美按兼职小时工资另行计算，不进入本实时预估模型。

## 管理员流程

工作台进入“实时薪资”，可使用六个功能页签：

1. 实时工资：查看员工明细、已知项预估合计和数据完整状态。
2. 员工参数：设置含社保补贴的基本工资、房补、满绩效、提成比例、提成门店、全勤奖及生效日期。
3. 绩效规则：设置三项权重、迟到扣分、等级区间和金额系数。
4. 营业收入：按门店和截止日期选择收银系统同步或手动设置提成计算基数；西直门实际营业额始终以银豹 API 为准，并可按管理员设置的时段和频率自动更新当天明细。
5. 处罚：事件等级自动带出默认绩效扣分，可上传处罚图片；发布后通知员工，并支持保留原因后撤销。
6. 加班：配置默认 25 元/小时的加班时薪，并查看全部加班申请和审批状态。

所有参数按生效日期保存历史。员工工资参数的修改原因为选填，参数仍须经管理员勾选确认才会被视为完整数据。员工和店长可从工作台提交加班：员工申请由对应门店店长审批，店长申请由管理员审批，只有审批通过后才计入预估工资。

绩效规则页下方会实时解释任务、考勤、纪律三部分得分，以及 A/B/C/D 等级对应的绩效金额系数。工资详情中的待更新条目可直接跳转到员工参数、营业收入或任务管理等对应维护位置。

加班填报只允许选择今天或过去 5 日内的日期，小时数按 0.5 小时递增，加班说明为选填。今天或过去 5 日内提交的申请可以在“加班记录”中修改；修改后原审批结果失效，并重新进入对应层级的审批流程。加班记录同时展示所选月份的通过小时汇总和加班工资汇总。

## 数据库实现

- `payroll_employee_rules`：员工工资参数历史。
- `payroll_employee_commission_stores`：员工提成门店。
- `payroll_performance_rules`：绩效规则历史。
- `payroll_store_revenues`：每日已确认营业收入，同时记录手动、银豹或企迈来源。
- `payroll_store_revenue_inputs`：记录某门店在某个截止日期选择的提成营业额来源，以及可选的手动月累计金额。
- `pos_sales_integrations`：收银系统与门店的映射、启停状态和自动更新计划，不保存 App Key。
- `pos_sales_sync_jobs`：每次手动或自动更新的结果、单据数量、接口调用次数与错误摘要。
- `pos_sales_tickets`：用于核算收入的最小化单据记录；无效单据不计收入，退货单从收入中扣减。
- `payroll_penalties`：其他罚款和纪律扣分。
- `payroll_penalty_assets`：处罚图片元数据，原图保存在私有 Storage。
- `payroll_overtime_rates`：加班时薪生效历史。
- `payroll_overtime_requests`：员工或店长加班申请、分级审批和审批时薪快照。
- `get_payroll_estimate`：员工本人或有权限管理员读取单人预估。
- `admin_payroll_estimates`：管理员读取人员列表与合计。

截止日期统一使用北京时间，避免 Supabase UTC 日期在北京时间凌晨误判为未来日期。

西直门银豹接入、凭据配置、手动更新和自动计划的部署说明见 `docs/POS_SALES_SYNC.md`。
