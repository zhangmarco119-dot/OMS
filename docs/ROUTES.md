# 页面路由

| 路径 | 阶段 | 页面 | 说明 |
| --- | --- | --- | --- |
| `/` | 9+ | 系统入口 | 自动进入管理系统，未登录时跳转登录页 |
| `/login` | 3/9+ | 登录页 | 使用账号名或姓名登录，服务端对接 Supabase Auth |
| `/app` | 3/9+ | 角色首页 | 员工显示点货/订货入口；管理员显示提交消息中心 |
| `/app/messages` | 9+ | 管理员消息 | 与管理员首页相同，用于查看最近提交提醒 |
| `/app/inventory` | 5/9+ | 点货工作台 | 员工点货录入、汇总和数据库提交；管理员访问时显示权限说明 |
| `/app/order` | 6/9+ | 订货工作台 | 员工订货录入、无需订货、汇总和数据库提交；管理员访问时显示权限说明 |
| `/app/arrivals` | V2-3 | 到货上报 | 员工和店长共享草稿、图片、商品、多明细、自动保存和提交；管理员不能执行 |
| `/app/arrivals/history` | V2-3 | 到货历史 | 查看当前门店已提交、已查看和已作废到货记录 |
| `/app/arrivals/:reportId/success` | V2-3 | 到货提交成功 | 展示正式编号和自动描述，支持查看记录、返回工作台或继续下一批 |
| `/app/history` | 7/9+ | 提交记录 | 员工看本人记录，店长看本店记录，管理员看授权门店全部记录和明细 |
| `/app/account` | 8 | 账号设置 | 本人密码修改 |
| `/app/account/about` | 9+ | 关于系统 | 仅管理员查看当前版本和历次中文更新摘要 |
| `/app/admin` | 8/9+ | 后台管理 | 商品增删改、Excel 导入和用户管理，保留管理员底部导航 |
