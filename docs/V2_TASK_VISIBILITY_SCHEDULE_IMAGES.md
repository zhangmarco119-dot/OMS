# StoreHub V2：任务可见性、周期截止与图片预览

## 可见性

任务模板是管理员的配置源。员工和店长不能读取或看到已发布模板；只有管理员从模板创建并发布门店任务实例后，任务才会显示在当前门店的任务中心。

## 周期截止时间

模板可设置：

- 每周：截止星期和完成时间；
- 每月：截止日和完成时间；
- 不重复：发布任务时由管理员选择本次截止时间。

周期模板在发布任务时自动带入下一次未来截止时间，管理员仍可对本次任务调整。每月 29–31 日在没有该日期的月份会自动取该月最后一天。

## 图片

任务图片保存在私有 `v2-task-images` bucket。员工/店长上传后可在自己的任务界面预览；管理员在审核详情中也会通过短期签名链接预览。图片访问继续受任务和门店 RLS 约束。

图片支持连续上传多张。点击缩略图会在当前页面全屏查看，再次点击图片或关闭按钮即可返回。

## 自动周期任务

管理员创建任务时可选择：单次任务、每 N 天一次，或每周指定一个或多个截止日。创建周期计划后会立即推送首个任务；数据库定时任务每 5 分钟检查一次，在当前周期截止后自动生成并推送下一周期任务到对应门店的员工和店长账号。管理员可暂停计划。
