## 目录职责

|目录|当前用途/处理原则|

|src|共用 React 业务系统|

|inputdoc / jiaban / outputs|用户业务材料/产物，未跟踪，保留原位|
|qmai-cli-main|用户已有企迈辅助工具，非 StoreHub 主服务，保留|
|.tmp / .codex-remote-attachments|本地测试产物/附件，忽略文件也不代表可全部删除|
